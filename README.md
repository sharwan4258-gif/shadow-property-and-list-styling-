## 🧪 Concepts & Code Covered

### 1. 📋 CSS List Styling (`list-style`)
- **Flexbox Navigation:** Building simple navigation layouts using `<ul>` and `<li>` with `display: flex`.
- **List Marker Positioning:** Using `list-style-position: inside` vs `outside`.
- **Custom List Types:** Changing default markers using `list-style-type` (e.g., `decimal`).
- **Custom List Images:** Adding custom bullet icons via `list-style-image`.

### 2. 🌓 CSS Box Shadow (`box-shadow`)
- Syntax structure: `h-offset v-offset blur-radius spread-radius color`.
- Adding realistic drop-shadow effects to block elements (e.g., `5px 15px 5px rgba(...)`).

### 3. ✍️ CSS Text Shadow (`text-shadow`)
- Applying soft and blurred color offsets directly to typography elements (`10px 10px 10px rgb(...)`).

### 4. 🔲 Border vs Outline Differences
- Practical distinction between `border` (takes space in the Box Model) and `outline` (drawn outside element boundaries without affecting layout).
- Customizing outlines using `outline-offset` and seeing how `border-radius` affects element borders.
