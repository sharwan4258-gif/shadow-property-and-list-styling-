## 📑 Concepts Covered

### 1. 🌓 CSS Box Shadow (`box-shadow`)
Allows you to add cast shadows around an element's frame.
- **Syntax:** `box-shadow: h-offset v-offset blur-radius spread-radius color inset;`
- **Key Features Included:**
  - Standard soft box shadows for cards and containers.
  - Multi-layered shadows for realistic depth.
  - Inner shadows using the `inset` keyword.

### 2. ✍️ CSS Text Shadow (`text-shadow`)
Adds shadow effects to text content to improve readability or add dramatic styling.
- **Syntax:** `text-shadow: h-offset v-offset blur-radius color;`
- **Key Features Included:**
  - Basic drop shadows for headings.
  - Neon/Glow text effects using larger blur radii.
  - Multi-directional text shadows.

### 3. 📋 CSS List Styling (`list-style`)
Customizes ordered (`<ol>`) and unordered (`<ul>`) lists beyond standard browser defaults.
- **Properties Demonstrated:**
  - `list-style-type`: Custom bullet markers (circle, square, roman numerals, none, etc.).
  - `list-style-position`: Controlling marker placement (`inside` vs `outside`).
  - `list-style-image`: Replacing standard bullet points with custom icons/images.
  - Creating clean navigation bars and custom lists using `list-style: none`.
